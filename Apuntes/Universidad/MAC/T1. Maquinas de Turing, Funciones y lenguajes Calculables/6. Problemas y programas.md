
>[!def]
>**Problema**:
>?
>Un problema *PROBLEMA(X)* o *PROBLEMA* consta de:
>- Un conjunto X de entradas. Un elemento $x \in X$ se llama una entrada.
>- Un conjunto Y de soluciones. Un elemento $y \in Y$ se llama una solución.
>- Una aplicación $F:X\rightarrow 2^Y$ que asigna a cada entrada $x \in X$ un conjunto $A \subseteq Y$ de soluciones posibles

>[!example]
>Búsqueda de caminos en grafos dirigidos: 
>- Entradas X: conjunto formado por las tripletas $(G,n_s,n_l)$, donde G es un grafo dirigido, $n_s$ es un nodo de salida, $n_l$ es un nodo de llegada. 
>- Conjunto Y : lista de nodos $(n_1,\dots,n_k )$ 
>- $F(G,n_s,n_l)$ es el conjunto de las listas de nodos $(n_1,\dots ,n_k)$ tales que $n_1 = n_s,n_k = n_l$ y todas las parejas $(n_i ,n_i+1)$ sean arcos de G.

## Tipos de problemas:

>[!def] roblemas de Búsqueda
> Son los problemas genéricos cuando $F(x)$ puede ser vacío o contener varios elementos: Para una entrada $x$ el problema consiste en encontrar una solución $y$ que cumpla una relación con $x$ cuando este exista y decir $NO$ cuando $F(X)=\emptyset$
> >[!example]
> >Dado un grafo no dirigido, encontrar un circuito hamiltoniano
> >

>[!def] Problemas de Decisión
>Son aqueyos en los que las soluciones son $Y=\{SI,NO\}$ y cada entrada $x$ tiene asociada una única solución.
>>[!example] 
> Dado un grafo determinar si tiene un ciclo hamiltoniano ^d9rk7d

>[!def] Problemas de optimización
> La solución optimiza (minimiza o maximiza) una función definida sobre un conjunto de soluciones factibles asociadas a la entrada
> >[!example]
> >El problema del viajante de comercio

>[!def] Problemas de función
> Cada entrada $x$ tiene siepre una y solo una solución: $F(x)$ tiene un solo elemento.
>> [!example]
>> Dado un número $n$ calcular $n^2$ ^ktnch3

 En [[6. Problemas y programas#^ktnch3|problemas de función]] y en [[6. Problemas y programas#^d9rk7d|problemas de decisión]], a la solución que le corresponde a la entrada $x$ se le denota también por $PROBLEMA(x)$


### Versiones de los problemas de Decisión.

Los problemas de decisión tienen la característica de ser simples y de que, al final, todo problema tiene asociado un problema de decisión asociado.

>[!example] Problemas de umbral para optimización
>Los mismos datos de un problema de optimización más un umbral K y ahora se pregunta si existe una solución de valor mayor o menor que el valor K según sea un problema de máximo o mínimo

>[!example] Problemas de existencia para problemas de búsqueda:
>Dado un x, determinar si existe un y tal que sea una solución de x.

>[!example] Problemas de comprobación para problemas de función y búsqueda: 
>Dado x y una posible solución y determinar si y es
una solución de x.

### Problemas de decisión y lenguajes

Se puede definir un *lenguaje* sobre un problema computacional de decisión en el que las entradas se codifican como palabras del alfabeto $A$ con el lenguaje de las entradas que tienen respuesta *SI*:$$L(\text{PROBLEMA}(x))=\{x \in A^*:\text{PROBLEMA}(x)='\text{SI}'\}$$
>[!important]
>Un lenguaje $L$ sobre un alfabeto $A$, siempre define también un problema de decisión: dada $X\in A^*$ determinar si $x \in L$
>

### Problema del contrario

Dado un problema de decisión PROBLEMA, el problema contrario de PROBLEMA, es el problema C − PROBLEMA que intercambia las salidas $’SI’$ y $’NO’$ o de forma más precisa $\text{PROBLEMA}(x) =′ SI ′ ⇔ C − \text{PROBLEMA}(x) =′ NO′$

>[!note] Problemas Contrarios y lenguajes
>El lenguaje asociado al problema contrario del *PROBLEMA* es el lenguaje complementario del lenguaje asociado a *PROBLEMA*
>$$L(C-\text{PROBLEMA}) = \overline{L(\text{PROBLEMA})}$$
